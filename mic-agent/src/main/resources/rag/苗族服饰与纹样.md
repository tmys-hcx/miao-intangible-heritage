# 苗族服饰与纹样
## 服饰形制
苗族支系众多，素有"百苗"之称，服饰形制丰富多样，但大体为上衣下裙结构：交领或对襟上衣配百褶裙，外系围腰、飘带，盛装时加披银衣。雷山、台江一带保留长裙、中裙传统，雷山大塘一带有裙长仅二十厘米左右的"短裙苗"服饰；榕江、丹寨的"百鸟衣"以羽毛、鸟纹装饰，与锦鸡舞一同闻名。

## 盛装与便装
便装朴素轻便，以家织土布为主；盛装则集合刺绣、蜡染、织锦与银饰于一身，是节庆与婚嫁的礼仪装束，一整套盛装往往需要母女两三代人经年累积制作。

## 纹样母题
苗族服饰纹样被称为"穿在身上的史书"，常见母题包括：
- 蝴蝶妈妈：万物之母，苗绣、蜡染中最核心的纹样。
- 鹡宇鸟、苗龙、鱼、枫树：源自创世古歌，苗龙多带牛角、鱼尾，鱼寓多子多福。
- 铜鼓纹、涡旋纹：象征祭祀与太阳崇拜。
- 山川田原纹：以方格、曲线示意田地与江河，铭记祖先迁徙之路。

## 色彩与织造
苗服底色多为黑色、藏青，上施大红、玫红、翠绿、宝蓝等对比色，浓烈明快。苗族织锦以木机手工织造，常用于袖口、飘带与背扇装饰；苗族织锦技艺与服饰相关技艺已列入国家级非物质文化遗产代表性项目名录。

## 文化意义
服饰纹样是苗族支系识别、年龄与婚否的标志，也是无文字社会中传承历史记忆的重要方式。
