# 苗族银饰锻制技艺
## 概述
苗族银饰锻制技艺是苗族传统金属手工加工技艺，2006 年入选第一批国家级非物质文化遗产代表性项目名录，是苗族文化最具代表性的物质载体之一。
苗族对银有着独特而深厚的审美崇拜，素有"以银为美、以重为贵"的观念。银饰不仅是大自然的馈赠被巧手幻化成的艺术，更凝聚着苗族的财富观、信仰观与审美观。在重大节庆、婚嫁盛典中，苗族女子头戴高耸银角、颈挂层层项圈、身缀成片银衣，整套盛装银饰可达数公斤。银饰随步伐、舞姿叮当作响，光芒流转，与盛装刺绣相映生辉，极具震撼的视觉与听觉感染力。
银饰是苗族家族财富与身份的直接象征。旧时苗家女儿出嫁，父母倾其积蓄打制全套银饰作为嫁妆，一套银饰往往承载一个家庭数代人的积累与情感，可代代相传，既是传家宝，也是家族兴旺的标志。

## 种类
苗族银饰体系庞大、形制繁多，按佩戴部位可分为五大类：
- 头饰：银角（牛角形银角宽大高耸、造型最醒目，常以錾刻龙凤、花卉装饰，是盛装礼仪中最核心的头饰）、银冠、银梳、银围帕、银簪、银抹额。
- 颈胸饰：项圈（分实心、空心、多层圈叠戴等形式，层层叠绕脖颈）、银链、银压领、银锁（寓意锁住生命、护佑平安）。
- 手饰：手镯（有螺旋形、绞丝形、雕花形等）、戒指、银钏。
- 耳饰：各式耳环、耳柱，造型多样。
- 衣饰：银衣片、银泡、银铃、银花坠，密布钉缀于盛装衣背、衣襟、袖口与围腰，是整套银饰中数量最大、最富动感的组成部分。

## 锻制工艺
苗族银饰全部依靠手工锻制，没有标准化模具，工序繁复，主要流程包括：熔炼、浇铸、拉丝、锤揲、錾刻、镂空、编结、焊接、抛光。整套工序环环相扣，考验匠人的经验与耐心。
其中，拉丝与錾刻最见功力：
- 拉丝：匠人将银条反复加热拉拔，可拉出细如发丝的银丝，用于编结银链、银花、银坠，做工极为精细。
- 錾刻：匠人左手持錾子、右手握小锤，在银片上凭眼力与手劲敲出繁复细腻的图案，纹样繁而不乱，错落有致，一件银饰往往需要上万次敲击才能完成。
  此外，镂空与编结赋予银饰通透轻盈的质感，焊接与抛光则为银饰收束成完美的光泽。
  贵州黔东南雷山县控拜村是远近闻名的"银匠村"，村里世代传承银饰锻制手艺，许多银匠家族一门数代以此为业，技艺通过父子、师徒口传手教代代延续，是研究苗族手工技艺传承的典型村落。

## 纹样与寓意
苗族银饰上的纹样与苗绣、蜡染纹样一脉相承，是苗族无文字社会里"穿在身上"的文化密码，常见纹样包括：
- 蝴蝶妈妈：苗族创世神话中的万物之母，是苗绣、蜡染与银饰中最核心、最神圣的纹样，寄托着对始祖的追怀与敬畏。
- 苗龙：苗族独有的龙形象，多带牛角、鱼尾，造型与汉族龙迥异，象征护佑村寨、风调雨顺。
- 鱼：因"鱼"谐音多子，寓意多子多福、家族繁衍兴旺。
- 鸟与枫叶：源自苗族创世古歌，枫树是苗族生命起源的象征符号，承载着祖先迁徙的古老记忆。
- 铜鼓纹、涡旋纹：源于祭祀与太阳崇拜，反映苗族先民对自然与天地的敬畏。
  银冠上密布的银泡则象征漫天星辰，寓意与天地同在、祈福纳祥。这些纹样共同寄托着苗族的祖先崇拜、自然崇拜与对吉祥安康的祈愿。

## 佩戴习俗
苗族银饰一般不在日常佩戴，主要在苗年、姊妹节、鼓藏节等重大节庆，以及婚嫁仪式中成套穿戴，是礼仪盛装的重要组成部分。
婚嫁时，新娘身着全套盛装银饰，既是身份与美丽的展示，也是家族财富的象征。银饰作为重要的嫁妆，常由母系代代相传，凝聚着家族的记忆与祝福。
值得注意的是，不同苗族支系的银角造型、项圈形制与银饰纹样存在明显差异，通过观察银饰的样式，往往可以区分佩戴者所属的支系与地域，银饰因此也承担着族群识别与身份标识的功能。
