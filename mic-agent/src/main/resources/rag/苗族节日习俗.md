# 苗族节日习俗
## 苗年
苗年是苗族最隆重、最核心的传统节日，相当于苗族的“新年”。黔东南地区苗族一般在农历十月到十一月间，依据苗族历法、谷物收成情况择吉日举办，用来庆祝一年丰收，祭祀祖先、感恩天地。
节前各家会清扫房屋、酿制米酒、打糍粑、杀年猪，准备丰盛食物。节日期间村寨集体举办踩芦笙、斗牛、斗鸟、赛歌、游街等民俗活动，整个节庆可以持续数天甚至十多天。苗年期间，全寨亲友互相走访拜年，身着盛装参加芦笙集会，是村寨凝聚、青年社交的重要时机。

## 姊妹节
苗族姊妹节主要流行于黔东南台江施洞、老屯一带，在农历三月十五前后举办，被称为“最古老的东方情人节”。
节日最标志性的物品是姊妹饭，姑娘们采摘红蓝草、枫树叶、黄饭花等天然植物染料，把糯米染成黑、红、黄、白、紫五色，蒸制成彩色糯米饭，用来馈赠亲友与心仪之人。姑娘们会悄悄在糯米饭里放入松针、竹钩、蒜、辣椒等信物，含蓄表达爱慕、拒绝或是约定再会的心意。
节日活动丰富，苗族女子穿戴全套银饰盛装游方、踩木鼓、对唱飞歌与游方歌，青年男女相聚交往，是苗族极具浪漫色彩的民俗盛会。

## 鼓藏节
鼓藏节，也叫牯藏节，是苗族规格最高、仪式最庄重的祭祖大典，属于苗族重大祭祀类非遗民俗。不同村寨祭祀周期不同，最普遍的是十三年一大祭。
苗族认为木鼓是祖先灵魂栖息之所，整个大典围绕“鼓”展开，分为迎鼓、醒鼓、祭鼓、送鼓等多个阶段。仪式中会举行吹芦笙、跳木鼓舞、宰牛祭祖等环节，流程繁复肃穆，需要村寨祭师主持。
鼓藏节不只是祭祀，更是凝聚宗族、传承古歌与祖先记忆的盛大集会，全族共同参与，以此缅怀先祖，祈求村寨平安、人畜兴旺。

## 其他节庆
- 吃新节：在农历六至七月，田间稻谷即将成熟时举办。人们采摘新谷稻穗，祭祀祖先，品尝新米饭，感念大地馈赠，祈求秋收丰收。不同地区吃新节时间略有差异，伴随芦笙、对歌活动。
- 芦笙节：以凯里舟溪甘囊香芦笙会最为出名，多在正月举办。方圆数十个村寨的芦笙队伍汇聚于此，吹芦笙、跳芦笙舞，同时开展服饰展示、赛马、斗鸡等活动，是规模宏大的芦笙文化盛会。
- 四月八：流行于贵阳、惠水、龙里等苗族聚居区域，为纪念苗族古代英雄而设立。当天苗族民众聚集集会，吹芦笙、对歌、跳舞，传承民族历史记忆。
- 跳花节：主要流行在黔西北毕节一带。节日会设立跳花坡，苗族青年男女聚集于此，吹芦笙、载歌载舞，交友择偶；同时还有斗牛、赛马等活动，是当地最重要的社交节庆。

## 社交与礼俗
游方，在黔西北又称为跳月、赶花场，是苗族延续千年的传统社交习俗。村寨专门划定游方场，未婚青年男女在此相聚，以歌对话，互相了解，自由表达爱慕，是苗族传统婚恋文化的载体。
苗族待客礼仪极具特色，迎宾最经典的便是拦门酒。远方宾客到访时，苗家女子列队在寨门，端米酒、唱酒歌劝饮，以此表达热情与祝福。拦门酒搭配酒歌，是苗族迎接贵客的标志性礼俗。
