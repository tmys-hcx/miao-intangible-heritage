# 苗绣针法
## 概述
苗绣是苗族世代口传手教的传统刺绣技艺，2006 年入选第一批国家级非物质文化遗产代表性项目名录。苗族没有原生文字，苗绣被称作“针线织就的史书”，是承载民族创世神话、迁徙历史与审美信仰的载体。苗族女性自幼年便跟随母亲、祖母学习刺绣，从小穿针走线，在劳作间隙练习技艺。绣品大量应用于百褶裙、衣背、围腰、袖口、背扇、童帽、荷包等物件，不仅起到装饰作用，更是区分苗族不同支系、识别族群身份、记录家族记忆的重要文化标识。不同地域、不同支系的苗绣，针法、纹样、配色各有特色，也是地域文化最直观的外在体现。

## 主要针法
苗绣针法丰富多变，各支系各有擅长，核心经典针法如下：
- 平绣：苗绣里最基础、使用最广泛的针法，丝线顺着纹样平铺走针，针脚排布均匀整齐，绣面平整光洁，色彩过渡柔和，多用于描绘花卉、鸟兽、草木等相对细腻的平面花鸟纹样。
- 绉绣：属于高难度立体针法。匠人先把彩色丝线编织成细长的辫带，再将辫带按照纹样轮廓盘绕、固定在底布上，绣面会形成明显浮雕状立体隆起，触感厚重扎实，立体感极强，常用来表现苗龙、蝴蝶妈妈这类核心主体纹样。
- 破线绣：苗绣中极具代表性的精细针法，流行于台江施洞区域。匠人把一根粗蚕丝手工劈分成八至十六缕纤细的丝线再进行刺绣，丝线极细，针脚细密，绣面细腻平滑如同绘画，可以表现丰富的细节层次，是施洞苗绣标志性技艺。
- 堆绣：也叫叠布绣。先将彩色棉布或者绸缎裁剪、折叠成三角、菱形等小布片，再按照图案造型一层层堆叠、缝缀到底布上，形成错落的立体几何装饰效果，层次分明，视觉冲击力强，多用于背扇、衣摆的边框装饰。
- 锁绣（双针锁绣）：古老的刺绣针法，丝线环环相扣，连续编织成类似麻花辫的线条。绣线牢固耐磨，不容易脱线，大多用来勾勒纹样外轮廓，让图案边界清晰有力，在古老苗绣老物件中十分常见。
- 打籽绣：刺绣时反复绕线，在布面形成一颗颗饱满凸起的小圆“籽”，颗粒感突出，质感立体。一般用来表现花蕊、龙鳞、鸟眼等局部细节，点缀画面，增加纹样生动感。
- 数纱绣：也叫挑花，依托底布的经纬纱线，数着纱线的格数来落针走线，纹样工整对称，几何感极强，不需要预先打稿画样，全凭匠人心中构图。主要流行于湘西苗族地区，风格简约规整。

除以上核心针法外，还有辫绣、贴布绣、马尾绣（部分苗族支系使用）等特色针法，很多绣品并非只用单一针法，一件盛装绣片往往会组合多种针法，丰富画面层次。

## 纹样与寓意
苗绣纹样不是单纯的装饰图案，每一个纹样都承载苗族史诗、创世神话与原始信仰。蝴蝶妈妈是苗绣里最核心的母题，象征万物之母，是苗族始祖；鹡宇鸟在古歌里协助祖先完成民族迁徙，寓意护佑族群、指引前路；苗龙形象和中原龙不同，多长牛角、鱼尾，代表山林水泽的神灵，象征祥瑞与村寨护佑；鱼纹因多籽的特点，寓意多子多福、家族生生不息；枫树纹则关联蝴蝶妈妈从枫树化生的创世传说，是生命起源的符号。
纹样的排布、大小、组合方式，也暗含支系的历史故事，很多古老绣片记录了先民跋山涉水的迁徙路途。

## 色彩与地域风格
苗绣擅长运用大红、玫红、翠绿、宝蓝等高饱和度色彩，色彩对比强烈，浓烈明快，热烈奔放，底色常选用藏青、黑色土布，衬托彩色纹样更加鲜亮。不同地域形成了截然不同的地域风格：黔东南台江、施洞一带，以细腻的破线绣、厚重的绉绣闻名，纹样繁复华丽；雷山、丹寨苗绣风格古拙质朴，构图大气简练；湘西苗绣构图相对清秀细致，大量使用数纱挑花，线条干净规整。
一件完整的盛装绣片，往往耗费绣女数月甚至数年时间手工完成，一针一线都承载着苗家女性的情感与民族记忆。
