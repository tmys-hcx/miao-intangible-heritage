# 苗族蜡染工艺
## 概述
蜡染古称"蜡缬"，是中国古老的防染印花技艺，也是苗族世代传承的手工技艺，2006 年入选第一批国家级非物质文化遗产代表性项目名录。在苗族语言里，蜡染被称为"务图"，含义为"蜡绘之花"。贵州丹寨、安顺、镇宁一带的苗族蜡染最负盛名。苗族没有原生文字，蜡染布面上的纹样，同样属于“穿在身上的史书”，承载着苗族创世神话、祖先迁徙故事、自然崇拜，既是实用布料，也是民族文化的载体。苗族女性大多自幼学习点蜡绘图，不用提前打稿，仅凭心中记忆直接在布面下笔作画。

## 工艺流程
1. 备布：选用本地家织的棉土白布，先反复清洗去除浆料杂质，经过捶打让布面平整紧实，再上浆处理，让布料变硬挺，方便后续点蜡绘画，防止布料纤维吸收蜡液扩散。
2. 熔蜡：以蜂蜡为主，搭配白蜡按照固定比例调配，放入陶碗中隔水小火熔化。蜂蜡韧性好、不易脆裂；白蜡质地更脆，二者调配比例会直接影响后续冰纹的形成效果。
3. 点蜡：匠人使用特制三角形铜蜡刀，蘸取温热的蜡液，直接在处理好的白布上徒手绘制纹样。铜蜡刀薄而锋利，可自由勾勒粗阔线条或是纤细流畅的曲线，无需草稿，全靠代代相传的纹样记忆直接作画。蜡液冷却凝固之后，会在布面形成一层拒水蜡膜，这就是防染的关键。
4. 浸染：将绘好蜡膜的布匹放入蓝靛染缸反复多次浸染，颜色由浅逐步变深。染缸里的蓝靛染料，由板蓝、蓼蓝等本土植物的茎叶，经过长时间浸泡、发酵、沉淀制成，属于天然植物染料，色泽温润。每一次浸泡都需要取出晾晒氧化，反复循环才能达到浓郁沉稳的蓝色。被蜡膜覆盖的区域，染料无法渗入，保留原本布的白色。
5. 脱蜡：染色完成后，使用沸水烹煮布料，融化清除布面的蜡膜；也可采用刮刀刮除蜡层。蜡褪去之后，蓝底白花的纹样完整显现。回收的蜡可以重复使用，是传统工艺里节约材料的特点。
6. 漂洗、晾干：脱蜡后的布料反复清水漂洗，去除浮色残留，在通风处自然晾干，最终得到成品蜡染面料。

## 冰纹
在布匹浸入染缸的过程中，布面固化的蜡膜会因为布料拉扯、温度变化自然龟裂，蓝靛染液顺着细微的裂纹渗透进纤维，最终形成如同蛛网、冰裂一般细密自然的纹路，也就是蜡染独有的“冰纹”。冰纹是人力无法预先控制、不可复制的，每一块布料上的冰纹形态千变万化，独一无二。冰纹被视作苗族蜡染的灵魂，是自然与手工共同创造出来的美学特征，也让每一件蜡染作品都具有唯一性。

## 纹样与用途
蜡染的纹样体系和苗绣、银饰纹样一脉同源，常见纹样包含铜鼓纹、蝴蝶妈妈纹、鱼纹、涡旋螺旋纹、星辰几何纹、鸟纹、枫树纹等。纹样大多取材于苗族创世传说、祖先迁徙历史与身边自然万物，每一种纹样都带有寓意：蝴蝶妈妈代表始祖，鱼寓意多子多福，铜鼓纹代表祭祀与祖先崇拜，螺旋涡纹象征太阳、山川。
蜡染面料实用性极强，广泛用来制作衣裙、头帕、背扇、被面、包袱布、围腰等生活用品。在苗族的盛装体系中，蜡染常与苗绣、织锦、银饰互相搭配组合，共同构成一整套完整的苗族盛装，在苗年、姊妹节等各类民俗场合使用。

## 代表产地
贵州黔东南丹寨的扬武、排莫、排倒村寨，是苗族蜡染最核心的传承地，这里的蜡染纹样古朴大气，以大构图的动植物、几何纹样出名；贵州安顺、镇宁一带的苗族村寨则是另一大重要传承区域，当地蜡染构图更加细腻繁复，线条精巧。两地风格各有特色，都是苗族蜡染技艺重要的活态传承村落。
